ユーザー（10:02）
個人開発のクイズアプリに、2人でリアルタイム対戦できる機能を入れたい。どういう作りがいい？
Claude
候補は3つあります。WebRTC で端末どうしを直接つなぐ、Supabase Realtime で状態を配る、Cloudflare Durable Objects で対戦ごとに部屋を持つ、です。
サーバーを持たずに済む WebRTC が最も安く始められます。
ユーザー（10:15）
WebRTC だと、相手が回答を書き換えるズルを防げる？ 不正対策がいちばん大事。
Claude
防げません。WebRTC では正解の判定がそれぞれの端末で行われるので、改造した端末が勝ちを申告できます。
不正を防ぐには、正解の判定をサーバー側で行う必要があります。WebRTC 案は外します。
ユーザー（10:31）
じゃあ Supabase と Cloudflare のどっちにする？ サービスはこれ以上増やしたくない。
Claude
すでに Supabase を使っているので、Supabase Realtime にします。判定は Edge Function で行い、結果だけを Realtime で配ります。
Durable Objects は部屋ごとの状態を持てて有利ですが、サービスが1つ増えるので見送ります。
残る問題は、2人の回答がほぼ同時に届いたときにどちらを先とするかです。
