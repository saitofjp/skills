# 診断の手がかり

SKILL.md の判定を当てるときの、具体的な類型と言い回し。**網羅リストではない** — その文書に効くものを都度見つける方が重要で、ここにあるのは判定がぶれたときに参照する見本である。

## ステップ3: 装飾の4類型

判定は「その文を消して、読み手の動作が変わるか」。

### 重要だと言っているだけの文

悪化を抽象的に述べるだけで、読み手は何も避けられない。

- 「ここを飛ばすと、以降の判断がすべてぶれる」
- 「そこを潰すのが一番効く」
- 「これは極めて重要である」

**具体的な失敗を名指ししている文は装飾ではない。** 「部分だけ見て書き換え始めると、離れた場所にある重複が見えない」は、避けるべき動作を伝えている。

### 構造がすでに強制しているwhy

- 番号付き手順の「なぜこの順序か」 — 順序は番号が守らせている
- 禁止リストの中の「なぜ禁止か」
- 見出しが答えている「この節では何を説明するか」

判定を通ったwhyは、理由の説明ではなく**禁止に変換し、違反が起きる場所へ移す**。

```
Before（説明として、後の工程に）
  この工程を最後に置くのは、先に磨いても無駄であり、
  磨いた文には愛着が湧いて「守りを考えない」が働かなくなるからである。

After（禁止として、破りたくなる工程に）
  ここで一文の読みやすさを直さない。磨いた文には愛着が湧き、
  ステップ9の「守りを考えない」が働かなくなる。文はステップ11で直す。
```

### 結論を言い換えただけの理由

理由が結論の否定形になっていて、情報が増えていない。

- 「太字を増やさない。増やすとコントラストが下がるからである」
- 「テストを書く。書かないと品質が落ちるからである」

理由のチェーンも同じ。「AなのはBで、BなのはCだから」は深さ2以降をまず疑う。

### 読み手を身構えさせる文

判断の基準を与えないなら、構えさせて終わる。

- 「慎重に判断する必要がある」
- 「ここは難しいが」
- 「注意して進めること」

## ステップ3: 読み手に何も返していない語

- 「重要なのは〜である」
- 「〜という観点において」
- 「〜という点で」
- 「基本的に」「一般的に」「原則として」
- 「極めて」「非常に」「かなり」

## ステップ3: 3機構に当たる言い回し

| 機構 | 症状 | 例 |
|---|---|---|
| **計算させている** | 否定や条件が入れ子になり、結論の向きを読み手に計算させる | 「〜ないわけではない」「〜でない限り〜しないことはない」「〜がないとは言い切れない」 |
| **保持させている** | 被修飾語の前に長い修飾が積まれる、一文に複数のメッセージが入る | 「前回の調査で判明した設定ミスに起因する断続的な接続断の再発を防ぐための恒久対策」 |
| **復元させている** | 動作が名詞に固まる、「の」が3つ以上連なる | 「〜の実現」「〜への寄与」「〜の適用による改善」「機能の設定の変更の手順」 |

**否定を畳むときは向きを確認する。** 「負荷の増大を招かないとは言えない」は「負荷が増えることがある」であって「負荷が増えない」ではない。畳んで意味が変わるなら、畳まずに残す。

## ステップ5: 段階を外しやすい要素

### 補足に見えて核心

落とせば読み手が誤った判断をするのに、控えめな書き方で紛れ込んでいる。

- 判断の前提となる制約・前提条件
- 順序依存（「Aの前にBを実行する」）
- 間違えやすい類似物の区別

段階を下げる前に「これが無いと読み手は間違うか」を確認する。

### 核心に見えて補足

これらは重要さの証拠ではない。

- 見出しが付いている
- コードブロックがある
- 太字が多い
- 分量が多い — 分量が多いものほど、書き手が調べた順に書いただけの可能性が高い

## ステップ7: 構造へ移す／削る言い回し

### 省略で伝わる関係は書かない

主語・助詞・文脈で伝わるものを明示すると説明過剰になる。

```
本機能では、ユーザーが問題を選択することができます
→ 問題を選択できる
```

### 並列・順序は構造で示す

| 文章で書いているもの | 移す先 |
|---|---|
| 「まず〜し、次に〜し、最後に〜する」 | 番号付きリスト |
| 並ぶ項目を「〜や〜、および〜」で連ねる | 箇条書き |
| 「Aの場合はX、Bの場合はY、Cの場合はZ」 | 表 |
| 「〜だが、一方で〜」の対比 | 表の2列 |

### 説明的な前置きを削る

削っても意味が変わらないことが多い。

- 「〜については」「〜における」「〜に関して」
- 「〜という観点で」「〜の観点から」
- 「〜を行う」「〜を実施する」（→ 動詞1語に戻す）

### 接続の実況をやめる

「なお」「また」「ただし」「そして」の連打は、構造で示すべき関係を文章で肩代わりしている。段落を分ける、見出しを立てる、リストにする。
