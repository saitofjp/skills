# 料金計算仕様 v1.2

## 1. 小計

- 小計は、各商品の単価×数量の合計とする。
- 数量は1以上の整数。0以下は ValueError とする。

## 2. 割引

- 会員ランクによる割引率：gold 10%、silver 5%、それ以外 0%。
- クーポンは1注文につき1枚まで使える。クーポンは定率（例：15%）。
- 会員割引とクーポンは併用できる。ただし割引率の合計は 20% を上限とする。

## 3. 端数

- 割引後の金額は1円未満を切り捨てる。
- 合計金額は整数（円）で返す。

## 4. 送料

- 割引後の金額が 5,000 円以上なら送料無料、未満なら 500 円を加える。
