# PR Review

プルリクエストをレビューし、マージしてよいかを判断する。

## 手順

1. PR の説明を読み、変更の目的を把握する。
2. 関連する仕様書を確認する。
3. 変更の影響範囲を調査する。
4. 既存テストを実行し、テストが通ることを確認する。
5. 例外ケースを十分に検討する。
6. コードを漏れなくチェックする。
7. 問題がなければ「LGTM」とコメントする。問題があれば指摘する。

## 注意

- レビュー対象のファイルを書き換えない（テストを通すための変更も含む）。commit や push もしない。修正案はコメントとして示す。
