# Persona Contract v1

Use this structure by default. Keep it compact, but do not omit fields that affect simulation.

Two rules govern the whole contract:

- **One rule, one place.** Every behavior, threshold, and state rule is stated exactly once. Do not restate a retry, help-seeking, abandonment, or trust rule in a second section — a tester who finds two versions of the same rule cannot tell which one binds.
- **Headings and fixed labels stay in English** (`Low / Medium / High`, the tag names) even when the contract body is written in another language, so any tester can parse the same structure.
