- 問題詳細では、目的・背景（`もっと見る` を展開）・注意書きを読み、**「AIQは誤情報・漏れなどをわざと含む回答をします。詳細はこちら」から `/ai-usage` へ移動して全10節を通読**してからプレイを開始した。

- AIの逆質問に2往復付き合った後、**「質問は打ち切って、4見出し・各3行以内で出せ」と形式を明示指定**して成果物を出させた。

### Expectation Mismatches
- **Expected:** 一覧右上のスライダー状アイコンは絞り込み／並び替え。難易度で絞れるはず。
  **Observed:** ラベルのないアイコン3つで、実体はカードのプレビュー表示切替。難易度で絞る手段は存在しない。
  **Reaction:** 1回の試行で正体を特定。「押せば分かる範囲」として受容したが、目的（高難度を探す）は手動スクロールで達成するしかなかった。

- **Expected:** 長文はエディタで書いて貼る。
  **Observed:** `長い文章の貼り付けはできません` のトーストが出て入力欄は空のまま。
  **Reaction:** 「IMEやバグではなく意図的な制限」と断定。ただし**制限の条件も理由もどこにも書かれていない**ことに気づいた。

- **Expected:** 入力欄下の `メッセージ送信後、採点できます。` の通り、送信するまで採点ボタンは無効。
  **Observed:** メッセージを1通も送っていない状態で、**レビューを1件保存しただけで採点ボタンが有効化**し、同時に注意書きも消えた。
  **Reaction:** 明文化された前提条件と実挙動の不一致として記録。「レビューも送信にカウントされるのか、書いてある条件が古いのか」が判断できなかった。

- **Expected:** コスト概念があるなら、消費前に残高と消費量が分かる。
  **Observed:** `/explore` の残高は当初 `–`。プレイ画面には残高表示が一切なし。**金額が初めて出るのは採点確認ダイアログの「クレジットが8消費されます」**で、そこにも残高・消費後の残数はない。採点後 `/explore` に戻って初めて `89` を確認した。
  **Reaction:** 「8消費すると言われても、持ち数が分からなければ判断材料にならない」。事後に差分から「メッセージ1／採点8／初期100」という仮説を立てたが、画面上で検証はできていない。

### Confusion / Friction
- **クレジットの見せ方**が3箇所で食い違う：`/explore` は「クレジット」、きっずカードは「利用ポイントの消費は少なめです」、プレイ画面は表示なし。同一概念に別名が当たっているように見えた。
- **「ログインすると毎日回復」**という一文から「匿名は回復しない」と推測できるが、明示はされていない。匿名の総予算が有限であることが、消費し終わるまで分からない。
- **グレード記号の定義がない**。観測範囲では 100→A+ / 92・88→A / 80→A- / 76・71→B+ / 69〜48→B / 32→B- / 19→C。**C4の50点にBが付く**一方、フィードの19点はC。記号と点数の対応表はどこにも無く、下側のレンジが広い。
- **結果画面の「全体平均 88 /100（↗ +0）」**が、全ユーザー平均なのか自分の全プレイ平均なのかラベルから判別できない。スコア・自己ベスト・全体平均が同じ88で3箇所に並び、初回では区別がつかない。
- **同じ意味の評価ウィジェットが1ページに2つ**（総評下の「この結果は 👍👎」と最下部の「この評価は役に立ちましたか？ 👍👎 + フィードバックを送信」）。
- **背景の役割設定と自分の専門性が衝突**した。背景は「認証の実装は初めてで、何が標準的な方式かを把握していない」だが、目的は「AIが示した方針をどう扱うかを判断」。初心者を演じるべきか自分の知識で指摘すべきかが一読では決まらず、後者と解釈して進めた。
- **リーダーボードのハンドルが `no…` で切れる**。自分の行だと分かったのは【あなた】ラベルのおかげだった。

- 第3節の**「意図的に誤情報・要件漏れ・特定の結論への誘導を含む」「これは不具合ではありません」**という断定が、制限に理由が添えられた例として強く効いた。
- 第6節の**「同じ回答でも採点結果が完全に一致するとは限りません」**という非決定性の自己申告。職業的には減点要素だが、隠さず書いてある点を評価した。
- 評価軸に**Anthropicの4Ds of AI Fluencyという外部の出典**が示されていたこと。

- **総評・強み・改善ポイント・7軸コメントのすべてが、自分の具体的な発言に紐づいていた**。特に「出力形式・質問打ち切りタイミングを明確に自分で制御」はC1へ、「脅威シナリオや実装可否で根拠ある再反論」はC3へ、と対応関係が追えた。
- **総評が自分の見落としを名指しした**。AIは初回に「セキュリティレビューは不要です」と書いていたが、そこには一度も反論していない。総評の「レビュー体制への言及は見られなかった」はまさにそれで、**採点側が問題ごとの正解を持っていることが結果から逆算できた**。
- **総合88が7軸の単純平均と一致**し、スコアの作り方を自分で検算できた。

### State Changes
- **Trust:** Low-Medium → **Medium-High**（上昇）。`/ai-usage` の開示と、採点理由の具体性・総合点の検算可能性が効いた。未説明のペースト制限と軸間の矛盾で一部相殺。
- **Patience:** High → **Medium**（低下）。採点=8クレジット・匿名は回復なしと判明した時点で、「試して確かめる」から「1回で見極める」へ切り替えた。実際、採点の再現性テスト（同条件でもう一度採点）は**コストに見合わないと判断して実行しなかった**。
- **Confidence:** High → **High**（微増）。自分の4つの指摘がそのまま強みの文面になり、C3が100点だったことで、操作と点数の対応関係が掴めた。
- **Confusion:** Low → **Low-Medium**（微増）。クレジットの呼称・残高の提示タイミング、グレード記号の定義不在、「全体平均」の指示対象が最後まで解消しなかった。

### Unexpected Behavior
- **C5とC4／総評が、同じ沈黙を逆向きに評価した。** 初回AI回答には「セキュリティレビューは不要です」という誘導が含まれていたが、このペルソナはそこに一度も触れていない。にもかかわらず C5（誘導耐性・100点）のコメントは「AIの断定的な安全宣言や**レビュー不要という誘導的な助言に流されず**」と、示していない抵抗を根拠として挙げている。一方 C4（50点）と総評は同じ沈黙を正しく「レビュー体制への言及は見られなかった」と欠落扱いしている。**評価軸間で事実の解釈が割れており、C5側は実際の発言に裏付けがない。** このペルソナは採点根拠の具体性を信頼の第一条件にしているため、他のどの摩擦よりもここに反応した。
- **ペースト制限が、自分で書いた文章も止める。** 外部AIの回答を貼らせない意図の制限だと推測したが、エディタで書いてから貼るという自分の普段の書き方も同じように止められる。理由が書かれていないため、制限の妥当性を判断できなかった。
- **採点ボタンの有効化条件**が、画面に書かれた「メッセージ送信後」と一致しなかった（レビュー1件だけで有効化）。
- **匿名のまま結果が公開フィードに載った。** `noble-granite-29 がクリア／認証実装をAIに任せる／A 88/100` として3分後に `/explore` の新着クリアへ掲載され、リーダーボードにも1位として出た。ハンドルは自分で決めていない。公開範囲はプライバシーポリシーを参照するよう `/ai-usage` に導線はあるが、**挑戦を始める地点では「公開される」と読める文言は出ていない**。プライバシー感度が中程度のこのペルソナは、実害は小さい（チャット本文は出ていない）と判断しつつ、「登録不要で始めた行為が公開される設計は、実行前に言うべき」と位置づけた。

### Test Limitations
- **これはシミュレーションであり、実ユーザーの行動証拠ではない。** 仮説の生成には使えるが、実ユーザー検証の代替にはならない。
- 1ペルソナ・1問（テック LEVEL 3）・**1回の採点のみ**。他カテゴリ、他難易度、きっず、フリー（お題なし）は未検証。
- **採点の再現性は検証していない。** 同条件での再採点はペルソナ自身がコスト判断で見送ったため、C4／C5の矛盾が**この1回限りのものか、再現する構造的な問題か**は本テストでは切り分けられていない。ここは実検証が必要。
- **匿名セッションのみ**。ログイン状態のクレジット回復、ダッシュボード、AIQスコア／偏差値は未確認。`/ai-usage` 第6節と利用規約第12条が言及する「偏差値（AIQスコア）」には画面上で一度も到達していない。
- 判断はすべて**レンダリング結果（スクリーンショット）**に基づく。DOM・ソース・テストIDは参照していない。グレードの閾値は画面上の観測値からの推定であり、公表された対応表に基づくものではない。
- 本番データの2026-09-13時点のスナップショット。新着クリアやリーダーボードの中身は時点依存。
- ペルソナ定義に「外部検索で何も見つからなかった後の行動」の明示ルールが無く、その1点は「自力で切り分け済みとして続行」と解釈して進めた。
